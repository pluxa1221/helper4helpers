# Helper4Helpers

Простой плагин с одной простой задачей - дать возможность игрокам писать **свои вопросы**, а поддержке **отвечать** на них.

## Поддерживаемые версии

Проверена поддержка: 26.2.

## Функционал

Плагин позволяет писать вопросы и, соответственно, отвечать на них. Для этого у него есть две команды:

* `/ask <текст вопроса>` - задать вопрос
* `/answer <id> <текст ответа>` - ответить на вопрос

При публикации нового вопроса все игроки с правом `helper4helpers.answer` (см. [Права](#Права)) получают уведомление, когда кто-то из хелперов отвечает на вопрос игрок сразу же получает этот ответ, если он, конечно, на сервере, а хелперу (в планах) будет выдаваться награда.

Если написать `/answer` он выведет подобный список вопросов:

```
=== Список вопросов ===
1. Первый вопрос
2. Второй вопрос
3. Не первый, и не последний вопрос...
```

Где `id` это 1, 2 и 3.

## Права

| Задать вопрос        | Ответить на вопрос      |
| :------------------: | :---------------------: |
| `helper4helpers.ask` | `helper4helpers.answer` |
| Выдаётся игрокам     | Выдаётся хелперам       |
